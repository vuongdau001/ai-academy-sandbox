# .agents

Thư mục cấu hình dành cho agent. Qua từng chặng của khoá, đây là nơi bộ công cụ của
bạn lớn dần — rules, skills, workflows, hooks.

`mcp_config.json` là file **bạn tự tạo** ở module đầu tiên. Nó bị `.gitignore` chặn vì
chứa token cá nhân của bạn. Khối cấu hình để dán vào lấy ở
nút **Cấp token MCP** trên trang module — chỉ chỗ đó mới có token của bạn và đúng địa
chỉ server của môi trường bạn đang học.

Quy ước skill: `.agents/skills/<tên>/SKILL.md`.
